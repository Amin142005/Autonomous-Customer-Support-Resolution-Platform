# Scope

Confirm whether message creation, notifications, or all synchronization stopped.
Check whether the service or Slack is reporting an incident.

# Authorization

Review integration status and authorization age. A revoked or expired
authorization may require the workspace owner to reconnect the integration.

# Resolution

Guide the approved reconnect process. Escalate repeated authentication failures
with the integration name and timestamp, without collecting Slack credentials.
